## O problema, na voz do cliente
"Preciso cadastrar as marcas de carros e consultar essas informações de forma rápida. Quando os dados ficam espalhados ou são anotados manualmente, fica mais difícil encontrar e atualizar as informações."

## Propósito

O sistema tem como propósito organizar o cadastro de marcas de carros em um único lugar. Atualmente, informações sobre as marcas podem ser registradas de forma manual ou desorganizada, dificultando a consulta e a atualização dos dados. O sistema permitirá cadastrar, consultar, editar e excluir as marcas de maneira simples e organizada.

## Objetivo

Com o sistema funcionando, todas as marcas de carros cadastradas estarão armazenadas de forma organizada. O usuário poderá consultar rapidamente as marcas existentes e também poderá adicionar novas marcas, alterar informações de marcas já cadastradas ou excluir registros que não sejam mais necessários.
## Quem usa

Usuário. Pessoa responsável por utilizar o sistema para cadastrar, consultar, editar e excluir marcas de carros.

O usuário será responsável pelo gerenciamento das informações cadastradas no sistema.

## Escopo
O sistema cadastra marcas de carros.

O sistema permite consultar as marcas cadastradas.

O sistema permite editar os dados de uma marca.

O sistema permite excluir uma marca cadastrada.

O sistema organiza e apresenta as marcas cadastradas de forma simples.

O sistema permite localizar uma marca através da consulta dos registros.
## Fora do escopo
Cadastro de veículos completos, pois o objetivo inicial do projeto é trabalhar somente com as marcas.

Cadastro de concessionárias, pois essa funcionalidade não faz parte da proposta inicial do sistema.

Controle de vendas ou estoque de veículos, pois o sistema será voltado apenas para o gerenciamento das marcas.

Sistema de financiamento de veículos, pois essa funcionalidade não está relacionada ao objetivo principal do projeto.

## Características principais

O sistema funcionará através de uma interface simples e poderá ser utilizado para gerenciar as marcas de carros cadastradas. O usuário poderá adicionar, consultar, editar e excluir registros. As informações serão armazenadas de forma organizada, facilitando a manutenção e a consulta dos dados. O sistema terá como foco a facilidade de uso e a rapidez para realizar as operações de cadastro.
