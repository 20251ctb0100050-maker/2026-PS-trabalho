# 4.1 Descrição do Projeto

## O problema, na voz do cliente

"Recebemos os pedidos de corte de madeira pelo WhatsApp, mas, como as informações ficam espalhadas nas conversas, às vezes fica difícil encontrar os pedidos e saber quais ainda precisam ser entregues."

## Propósito

O sistema tem como propósito organizar os pedidos de corte de madeira em um único lugar. Atualmente, os pedidos são recebidos pelo WhatsApp, o que pode dificultar a localização das informações e o acompanhamento das entregas. O sistema permitirá cadastrar, consultar e atualizar os pedidos, facilitando a organização do trabalho.

## Objetivo

Com o sistema funcionando, os pedidos de corte de madeira estarão armazenados de forma organizada. O usuário poderá registrar os pedidos dos clientes, consultar suas informações, atualizar o andamento dos pedidos e identificar quais ainda estão pendentes e quais já foram entregues.

## Quem usa

Irmão do estudante, responsável pelo recebimento e gerenciamento dos pedidos de corte de madeira, junto com seu pai.

Os usuários utilizarão o sistema para organizar os pedidos dos clientes e acompanhar as entregas.

## Escopo

O sistema permite cadastrar os pedidos dos clientes.
O sistema permite registrar as informações de cada pedido.
O sistema permite consultar os pedidos cadastrados.
O sistema permite editar as informações de um pedido.
O sistema permite atualizar o andamento dos pedidos.
O sistema permite identificar os pedidos pendentes e os que já foram entregues.

## Fora do escopo

Controle financeiro, pois o objetivo inicial do projeto é organizar os pedidos e acompanhar as entregas.
Controle de estoque de madeira, pois o sistema não terá como finalidade gerenciar a quantidade de madeira disponível.
Controle de funcionários, pois o projeto será voltado ao gerenciamento dos pedidos.
Emissão de notas fiscais, pois essa funcionalidade não faz parte da proposta inicial do sistema.

## Características principais

O sistema funcionará através de uma interface simples e permitirá organizar os pedidos de corte de madeira. Os usuários poderão cadastrar, consultar e editar pedidos, além de acompanhar o andamento das entregas. As informações ficarão armazenadas em um único lugar, facilitando a localização dos pedidos e evitando que seja necessário procurar os dados em várias conversas do WhatsApp.
